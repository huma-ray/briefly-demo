FAQ

Questions people ask first

If yours isn't here, the code is open on GitHub.

Can the assistant send a message without me?

No. Reading and summarizing run right away. Sending a Slack message, creating a ticket or changing a status always shows an approval card first, and nothing is written until you approve it.

Can it run on our own server?

Yes. The model is one setting. Point it at any OpenAI-compatible endpoint, including a vLLM server inside your network, and messages and tickets never leave it.

What can it see in Slack and Jira?

Only what your own account can see. It uses your token, not an admin key, so private channels and projects you can't open stay closed to it too.

Is the data in the demo real?

No. The demo uses a sample workspace with made-up people and messages. It resets every night at 03:00 KST, so feel free to approve, edit and cancel anything.

Can I buy Briefly?

Briefly is a demo project, not a product for sale. I build assistants like this for teams, connected to their own tools and data. If that's what you need, reach me on Upwork.
